Your AI companion, visibly present 讓 AI 對話真正擁有存在感

Give ChatGPT a face you choose. 讓你的 ChatGPT，有一張你選擇的臉。

AI FACE is a local-first Chrome extension that places a character beside your ChatGPT conversation. Choose a bundled persona, import your own image, move it, resize it, and let it react to ChatGPT audio—without an API key or a new chatbot. AI FACE 是本機優先的 Chrome 擴充功能，讓角色陪在 ChatGPT 對話旁。選擇內建角色、匯入自己的圖片、移動與縮放，並讓角色跟隨 ChatGPT 聲音反應；不需要 API Key，也不會建立另一個聊天機器人。

The public catalog intentionally starts empty. Only accepted packs appear after technical, rights, safety, and visual review. 公開目錄刻意從空白開始；只有通過技術、權利、安全與視覺審查的 角色才會出現。

No approved community personas yet 目前尚無核准的社群角色

A contribution path people can audit 每一步都能被檢查的投稿流程

Create, validate, review, vote, approve. 製作、驗證、審查、投票、最終核准。

GitHub is required only when changing the public catalog. It is not required to use AI FACE or import a personal character. 只有改變公開角色庫才需要 GitHub；一般使用與本機匯入不需要。

The current community contract requires a transparent 1024 × 1536 PNG plus a preview and manifest. Source photos, prompts, ZIP files, and unrelated assets are not accepted. 目前社群規格要求透明 1024 × 1536 PNG、預覽圖與角色資料。 不接受原始照片、提示詞、ZIP 或其他無關素材。

Honest privacy boundaries 誠實說明隱私邊界

Local-first does not mean invisible or encrypted. 本機優先，不等於隱形或加密保險箱。

AI FACE does not actively upload persona images. AI FACE 不主動上傳角色圖片。

Personal images are validated, converted, and stored in chrome.storage.local.

個人圖片在本機驗證、轉碼並保存於 chrome.storage.local。

Storage is local, not encrypted. 儲存是本機的，但沒有加密。

Other software with local access may still reach browser profile data.

可存取本機的其他軟體仍可能接觸瀏覽器資料。

Rendered pixels can still be captured. 畫面上的角色仍可能被擷取。

Origin isolation protects frame DOM access; it is not screenshot protection.

來源隔離保護 iframe DOM，不代表可以防止截圖或錄影。

No conversation reading. 不讀取對話內容。

Audio response uses bounded tab-audio features, not transcription.

語音反應使用有界的分頁音訊特徵，不做轉錄或內容辨識。

FAQ

The short answers. 你可能會先問的事。

Is AI FACE an OpenAI product? AI FACE 是 OpenAI 官方產品嗎？

No. AI FACE is an independent third-party project and is not affiliated with or endorsed by OpenAI.

不是。AI FACE 是獨立第三方專案，與 OpenAI 無隸屬或官方背書關係。

Do I need an OpenAI API key? 需要 OpenAI API Key 嗎？

No. AI FACE works beside the ChatGPT website and does not call a model API.

不需要。AI FACE 在 ChatGPT 網頁旁運作，不呼叫模型 API。

Can I install it from the Chrome Web Store? 現在可以從 Chrome Web Store 安裝嗎？

Not yet. The current Phase 6 build is an internal developer-mode trial.

還不行。目前 Phase 6 是需要開發人員模式的內部試用版。

Does community voting prove copyright ownership? 社群投票能證明投稿者有版權嗎？

No. Voting measures community interest. Rights, safety, and final maintainer review remain mandatory.

不能。投票只衡量社群興趣；權利、安全與維護者最終審查仍是必要門檻。
